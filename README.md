# Drape Studio

Curtain simulation for 3ds Max and V-Ray, by Designhaus Collective.

**Open it:** https://arashishkhanolkar-creator.github.io/drape-studio/

Hang a fabric panel, slide the clips along the rod to form folds with cloth physics, set the cloth, hem and floor, then export an all-quad OBJ for 3ds Max.

## Using it

- Works in Chrome, Edge and Safari, on a computer or an iPad.
- On an iPad, open the link in Safari, then choose Share and Add to Home Screen. It then opens like an app.
- Saved curtains are kept in the browser on each device.
- It needs an internet connection: the 3D library and the fonts load from the web.

## Files

- `index.html` is the whole product in one file.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` and `manifest.webmanifest` give it a home-screen icon and name.
